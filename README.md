GODIA PRIME CONNECT is a Kenyan digital business marketplace designed to connect retailers, shops, wholesalers, suppliers, distributors, and customers.

Our Mission

To connect businesses, expand market access, simplify product discovery, and create business opportunities across Kenya.

Main Features

- Business marketplace for discovering products.
- Supplier and distributor product listings.
- Product information, pricing, and stock details.
- Direct order requests.
- Customer support through phone and WhatsApp.
- Access to our Facebook page.

Technology

- HTML, CSS, and JavaScript.
- GitHub for source-code management.
- Cloudflare Pages for website hosting.
- Cloudflare Workers and D1 for backend services and database operations.

Deployment

The frontend build command is:

"npm run build"

The build output directory is:

"dist"

The build script copies "index.html" into the "dist" directory.

Important

The frontend and backend are separate components. Deploying the frontend does not automatically update or replace the existing Cloudflare Worker or database.

Backend integration, authentication, product synchronization, and order processing must be verified separately.
